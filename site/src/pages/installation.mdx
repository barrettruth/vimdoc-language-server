# Installation

## Cargo

```sh
cargo install vimdoc-language-server
```

## Nix

Run directly:

```sh
nix run github:barrettruth/vimdoc-language-server
```

Or add to your flake inputs:

```nix
inputs.vimdoc-ls.url = "github:barrettruth/vimdoc-language-server";
```

## From source

```sh
git clone https://github.com/barrettruth/vimdoc-language-server
cd vimdoc-language-server
cargo install --path .
```

## Editor setup

### Neovim

Using the built-in LSP client (Neovim 0.11+):

```lua
vim.lsp.config('vimdoc_ls', {
  cmd = { 'vimdoc-language-server' },
  filetypes = { 'help' },
  root_markers = { 'doc', '.git' },
  workspace_required = false,
})

vim.api.nvim_create_autocmd('FileType', {
  pattern = 'help',
  callback = function()
    vim.lsp.start(vim.lsp.config['vimdoc_ls'])
  end,
})
```

Pass `initializationOptions` to configure the server:

```lua
vim.lsp.config('vimdoc_ls', {
  cmd = { 'vimdoc-language-server' },
  filetypes = { 'help' },
  root_markers = { 'doc', '.git' },
  workspace_required = false,
  init_options = {
    lineWidth = 78,
    reflow = 'always',
  },
})
```

The `FileType` autocmd is needed because `vim.lsp.enable()` skips buffers
where `buftype` is not empty. Help buffers have `buftype=help`, so
`vim.lsp.start()` must be called directly.

The server activates on the `help` filetype. When a workspace root is found
via `root_markers`, cross-file features (diagnostics, references, rename) span
the workspace. Without a root (e.g. reading `:help`), the server still provides
formatting, hover, go-to-definition, and completion via external tag files.
