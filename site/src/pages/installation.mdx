# Installation

## Cargo

```sh
cargo install vimdoc-language-server
```

## Nix

Run directly:

```sh
nix run github:barrettruth/vimdoc-language-server
```

Or add to your flake inputs:

```nix
inputs.vimdoc-ls.url = "github:barrettruth/vimdoc-language-server";
```

## From source

```sh
git clone https://github.com/barrettruth/vimdoc-language-server
cd vimdoc-language-server
cargo install --path .
```

## Editor setup

### Neovim

Using the built-in LSP client (Neovim 0.11+):

```lua
vim.lsp.config('vimdoc_ls', {
  cmd = { 'vimdoc-language-server' },
  filetypes = { 'help' },
  -- buftypes = { 'help' },
  root_markers = { 'doc', '.git' },
  workspace_required = false,
})

vim.api.nvim_create_autocmd('FileType', {
  pattern = 'help',
  callback = function()
    vim.lsp.start(vim.lsp.config['vimdoc_ls'])
  end,
})
```

Pass `initializationOptions` to configure the server:

```lua
vim.lsp.config('vimdoc_ls', {
  cmd = { 'vimdoc-language-server' },
  filetypes = { 'help' },
  -- buftypes = { 'help' },
  root_markers = { 'doc', '.git' },
  workspace_required = false,
  init_options = {
    lineWidth = 78,
    reflow = 'always',
  },
})
```

The `FileType` autocmd is temporarily needed because `vim.lsp.enable()` skips
`buftype=help` buffers (tracked in [neovim#38380](https://github.com/neovim/neovim/issues/38380)).
